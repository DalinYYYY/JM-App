# 相电流采样 — PWM 触发 ADC 时序设计说明

> 适用板：SFOC（STM32G474，低边三电阻采样，电流检测放大器 INA199B1）
> 关联代码：[tim.c](../../../Board/SFOC/Core/Src/tim.c)、[adc.c](../../../Board/SFOC/Core/Src/adc.c)、[dev_half_bridge.c](../dev_half_bridge.c)、[dev_motor_phase_current.c](../dev_motor_phase_current.c)、[dev_config.h](../dev_config.h)
> 最后更新：2026-06-30

## 1. 背景与核心问题

低边三电阻 FOC，相电流只有在对应桥臂**下管导通**时才会流过采样电阻。采样链路为：

```
分流电阻(Rshunt) → INA199B1(增益50) → ADC 输入 → STM32 ADC 注入组
```

核心疑问：**直接用 PWM 边沿触发 ADC、不留运放建立时间，会不会因为放大器还没建立到位，采到错误的电流？**

结论先行：

1. **采样位置是对的** —— 触发点落在波峰（下桥全导通）附近，是低边采样应有的位置。
2. **存在真实风险** —— INA199B1 带宽仅约 80kHz，建立时间长。在**高调制（某相占空比大、下桥导通窗口窄）**工况下，该相电流会在运放尚未建立时被采走，读数偏小/失真。
3. **当前代码并没有"10µs 建立时间"** —— 实测触发点距波峰仅约 **706ns**，与设想的 10µs 不符。

## 3. PWM 与触发链配置（已核对代码）

### 3.1 定时器（TIM1）

| 参数 | 值 | 来源 |
|---|---|---|
| 计数模式 | 中心对齐 mode1 | [tim.c:48](../../../Board/SFOC/Core/Src/tim.c#L48) |

| RepetitionCounter | 0 | [tim.c:51](../../../Board/SFOC/Core/Src/tim.c#L51) |

PWM 频率验算：`170MHz / (2 × 8500) = 10.0 kHz` ✓，周期 **100 µs**（上数 50µs + 下数 50µs）。

### 3.2 ADC 触发

- 触发源：`ADC_EXTERNALTRIGINJEC_T1_CC4`，上升沿触发（[adc.c:102-103](../../../Board/SFOC/Core/Src/adc.c#L102-L103)）。
- 注入组 3 通道（IA/IB/IC），各 12.5 cycle 采样（[adc.c:92-126](../../../Board/SFOC/Core/Src/adc.c#L92-L126)）。
- 触发比较值：`HALF_BRIDGE_ADC_TRIG_CCR = 8380`（[dev_config.h:35](../dev_config.h#L35)），在 [dev_half_bridge.c:46-47](../dev_half_bridge.c#L46-L47) 写入 CH4。

### 3.3 触发时刻推导（关键）

CH4 为 PWM mode1：`OC4REF` 在 `CNT < CCR4` 时为高，`CNT ≥ CCR4` 时为低。ADC 取 `OC4REF` 上升沿。

中心对齐一个周期内 `CNT` 轨迹：`0 → 8500（波峰）→ 0`。

```
CNT
8500 ┤            ╱╲   ← 波峰：三相下桥全导通，电流全部流过分流电阻
8380 ┤          ╱    ╲ ← CCR4：下数经过 8380 时 OC4REF 上升 → 触发 ADC
     │        ╱        ╲
   0 ┤______╱            ╲______
            上数          下数
                    ↑
              触发点（波峰后约 706ns）
```

- `OC4REF` 上升沿出现在**下数**经过 `CNT=8380` 处。
- 距波峰：`(8500 − 8380) × 5.882ns = 120 × 5.882ns ≈ 706 ns`。
- **每个 PWM 周期触发一次**（PWM mode1 + 上升沿 → 单次），不会一周期两触发。

> 这同时回答了"是不是加了 10µs 延时"：**没有**，实际只有约 0.7µs 偏移。

## 4. 采样位置正确性分析

中心对齐下，波峰 `CNT=ARR` 时所有相 `CNT<CCR_phase` 不成立 → 高侧全关、**低侧全开** → 三相电流全部流过各自分流电阻，是低边三电阻最理想的采样点。

触发点偏波峰后 706ns，仍处于"低侧全开"区间（中低调制下该区间很宽），且远离开关边沿，**开关振铃已基本衰减**。

✅ 采样位置设计正确。

> 注：三相为**顺序转换**（非同步采样），相邻相之间约 `12.5cyc + 转换开销` ≈ 0.6µs 偏斜，对 10kHz 电流环可接受，但在高 di/dt 时是一个固有误差源。

## 5. 真正的风险：INA199B1 建立时间 vs 窄导通窗口

### 5.1 运放建立时间估算

INA199B1 增益 50V/V，带宽约 **80 kHz**（**请以数据手册为准**）。按单极点近似：

- 时间常数 `τ ≈ 1/(2π·80k) ≈ 1.99 µs`
- 建立到 0.1%（≈10bit）：`6.9τ ≈ 13.7 µs`
- 建立到 12bit（0.0244%）：`8.3τ ≈ 16.5 µs`

每个 PWM 周期，分流电阻上的电流是台阶信号（下桥导通才有电流，上桥导通近似 0），运放每周期都要从台阶重新建立。

### 5.2 低侧导通窗口宽度

设某相高侧占空比 `d = CCR_phase / ARR`，则该相**低侧导通窗口**（围绕波峰，连续）宽度为：

```
T_low = 2 × (ARR − CCR_phase) × 5.882ns = (1 − d) × 100µs
```

下侧从波峰前 `T_low/2` 开通。触发点在波峰后 0.706µs，故**从下侧开通到采样时刻**已过：

```
t_elapsed = (1 − d) × 50µs + 0.706µs
```

### 5.3 是否够建立时间

| 占空比 d | 低侧半窗 (1−d)×50µs | t_elapsed | ≥16.5µs(12bit)? |
|---|---|---|---|
| 0.50 | 25.0 µs | 25.7 µs | ✅ 够 |
| 0.68 | 16.0 µs | 16.7 µs | ⚠️ 临界 |
| 0.90 | 5.0 µs | 5.7 µs | ❌ 不够，读数错 |
| 0.95 | 2.5 µs | 3.2 µs | ❌ 严重不足 |

**临界占空比**（12bit 完全建立）：`t_elapsed ≥ 16.5µs → d ≤ 0.68`。
即占空比超过约 **68%** 的相，采样时运放尚未完全建立，电流读数偏小/失真。

> 这正印证了最初的直觉：不是纯理论担忧，**高调制工况下必然发作**。中低调制（d≲0.68）则无碍。

### 5.4 ADC 本身不是瓶颈

注入 12.5cyc @ 42.5MHz，单次约 `(12.5+12.5)/42.5M ≈ 0.59µs`，三相顺序 ≈ 1.76µs，仍落在波峰窗口内。瓶颈是**运放**，不是 ADC。

## 6. 验证方法（上板实测）

1. **标记采样时刻**：在 ADC 注入完成中断（[ADC1_2_IRQHandler](../../../Board/SFOC/Core/Src/stm32g4xx_it.c#L203) → JEOC）入口翻转一个空闲 GPIO。
2. **示波器对比**：同时探 INA199 输出 + 该 GPIO，**故意把某相占空比拉到 85~95%**，观察采样点是否落在运放输出仍在爬升的斜坡上。
3. **数触发次数**：确认每个 PWM 周期 `OC4REF` 上升沿只有一次（理论应为一次）。
4. **确认中断粒度**：当前用 `ADC_IT_JEOC`（[drv_adc.c:180](../../../Board/Driver/drv_adc.c#L180)，注：实际路径见 User/Driver/drv_adc.c），JEOC 为"每次注入转换完成"。3 个 rank 可能进 **3 次中断**；若期望"整组完成一次中断"应改用 `JEOS`。需上板确认中断进入次数。
5. **扫延时实验**：把触发 CCR4 当变量，从靠近波峰逐步前移，记录各占空比下电流读数随之的变化，定位建立不足的拐点。

---

## 7. 改进建议（按代价排序）

1. **限制最大调制比**（最低成本）
   保证最窄低侧窗口 > 运放建立时间。按 §5.3，限 `d ≤ 0.68` 可保 12bit 建立；放宽到 0.1% 判据可到 `d ≤ 0.74`。代价是牺牲母线电压利用率。

2. **两相重构采样**（软件，推荐）
   只用窗口最宽的两相实测，第三相用 `ia + ib + ic = 0` 重构。FOC 常规做法，可显著缓解窄窗问题。

3. **更换高带宽电流检测放大器**（根治）
   80kHz 对低边采样本就偏慢，换几百 kHz~MHz 级运放是最干净的解法。

4. **触发点微调**
   若坚持单点采样，可把 CCR4 进一步靠近波峰（如 8480），多争取约 0.6µs，但相对 16µs 量级的建立时间杯水车薪，仅作辅助。

## 9. 结论

| 维度 | 结论 |
|---|---|
| 采样位置 | ✅ 正确（波峰附近、低侧全导通、远离边沿） |
| 是否有 10µs 建立延时 | ❌ 没有，实际约 706ns |
| 不留建立时间会不会采错 | ⚠️ **中低调制不会**；**高调制（d≳0.68）会**，因 INA199B1 建立时间长（~16µs@12bit）远超窄窗 |
| 瓶颈 | 运放带宽（80kHz），非 ADC |
| 推荐措施 | 两相重构 + 限调制；根治则换高带宽运放 |

> 文中建立时间、临界占空比均基于"INA199B1 带宽 80kHz、单极点"近似，数量级可靠，精确值请以数据手册和上板实测为准。
