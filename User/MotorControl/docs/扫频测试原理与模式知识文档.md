# 扫频测试原理与模式知识文档

> 定位：面向伺服驱动开发的扫频测量知识手册，涵盖频响基础、级联控制链上的注入/测量原理、辨识与验证两方向的六种模式、偏置策略与实操安全要点。
>
> 读者：电机驱动/运动控制开发与测试工程师。不依赖具体代码实现，可作为团队知识分享材料。

---

## 1. 为什么伺服调参需要扫频

传统试凑法（Z-N、手动调参）有三个根本问题：

1. **激励不当**：阶跃激励幅值大，容易激发电流饱和、死区、静摩擦等非线性，测出来的"最佳参数"只在那个工况下成立。
2. **参数与物理脱钩**：没有对象模型，调出来的 Kp/Ki 不对应任何物理量（惯量、电感、摩擦），换电机或换负载就得从零重来。
3. **无法量化好坏**：除了"看起来稳了"，没有带宽、稳定裕度等客观指标，无法回答"还能不能提高性能""离稳定边界还有多远"。

扫频测量（Sine Sweep / Frequency Response Test）直接给出被控对象的**频率响应（Bode 图）**，它同时解决三个问题：

- **整定的输入**：从对象传函按带宽法直接换算 PID 初值，不靠试凑；
- **验收的依据**：闭环带宽、谐振峰值、相位裕度都是可量化、可复核的客观指标；
- **诊断的工具**：曲线形态异常（谐振峰位置、低频斜率）能直接指向模型错误或机械问题。

一句话：扫频把"凭手感调参"变成**测量 → 计算 → 验证**的标准工程流程。

## 2. 频率响应与 Bode 图：30 秒基础

对线性系统输入正弦 `A·sin(ωt)`，稳态输出是 `B·sin(ωt + φ)`。定义：

| 量 | 定义 | 物理含义 |
|---|---|---|
| 增益 | \|G(jω)\| = B/A | 该频率下信号的放大倍数（常用 dB 表示） |
| 相位 | ∠G(jω) = φ | 该频率下输出的滞后角 |
| 频率响应 | G(jω) | 逐个频率点测出的复数"放大器特性" |

把每个频率点的增益、相位画成两张图（横轴频率、纵轴增益 dB / 相位 deg），就是 **Bode 图**。

典型读数：

- **-3dB 带宽**：增益从低频值跌落 3dB 的频率——系统"跟得上"的极限速度；
- **转折频率**：一阶系统 = 1/(2π·τ)，直接暴露系统时间常数；
- **谐振峰**：机械弹性或控制裕度不足的标志；
- **相位滞后**：相位掉到 -90°/-180° 附近意味着控制难度急剧上升。

**测量的物理本质**：每个频点注入一段正弦，等暂态消失后，对稳态段做同步解调（与激励同频的复数相关），就得到该频点的 G(jω)。逐点扫频 = 逐点重建对象的频率特性。

## 3. 级联控制链：扫频的本质是"在哪注入、测什么"

伺服驱动是标准的**三级级联控制**：

```
 θ* ──►[位置环 P]──► ω* ──►[速度环 PI]──► iq* ──►[电流环 PI]──► Uq ──►[电气]──► T ──►[机械 1/(Js+B)]──► ω ──∫──► θ
```

理解扫频模式的三个关键认知：

1. **测到什么由两个选择决定**：激励注入点 + 测量点。注入在电流给定端、测量速度，测到的是"电流→速度对象"；注入在速度给定端、测量速度反馈，测到的是"速度闭环传函"。名字"X→Y"就是"注入 X、测 Y"。
2. **"开环"指被测环断开，不是所有环断开**。内环必须闭合才能充当理想的"执行器"：测机械对象时电流环要闭合（当转矩源用），否则测到的是电气+机械混在一起的复合对象。
3. **注入点越靠外，测到的传函包含的环节越多**。同一个"输出速度"，从力矩端注入测的是纯机械，从速度给定端注入测的是整个速度闭环，含义完全不同。

## 4. 辨识与验证：两个方向

扫频按用途分两个方向，共用同一套测试通道，区别只在环的配置、注入位置和偏置目的：

| 维度 | 方向一：辨识（整定前） | 方向二：验证（整定后） |
|---|---|---|
| 扫的对象 | 被控对象 G(s) | 闭环回路 T(s) |
| 环的状态 | 被整定环断开、内环闭合 | 全环闭合 |
| 注入位置 | 对象输入端（Iq 转矩、速度给定） | 各环给定端 |
| 直流偏置作用 | 避摩擦死区、定工作点 | 钉住线性工作点 |
| 输出用途 | 换算 Kp、Ki 初值 | 判带宽、峰值、裕度，给验收结论 |

**方向一：辨识 → 整定**

被整定的环断开、更内环保持闭合。典型如机械辨识：电流环闭合当转矩源（注入 Iq 正弦，编码器测速），速度环和位置环断开。拿到 G(s) = 1/(Js+B) 后按带宽法换算 PID 初值（见第 7 章）。

**方向二：验证 → 验收**

参数已装上，全环闭环，在各环给定端叠加正弦，测对应反馈量，得到闭环传函 T(jω)，从中提取带宽与稳定裕度指标（见第 7 章）。

**验证不达标的两种回法**（这是流程的关键闭环）：

1. 曲线形态与模型不符（谐振峰位置不对、低频斜率不对）→ **模型错了**，回到方向一重新辨识；
2. 形态对但带宽或裕度差 → **参数没调到位**，直接微调再验证。

## 5. 六种测试模式详解

### 5.1 总表

| 模式 | 方向 | 位置环 | 速度环 | 电流环 | 测到的传函 | 偏置加在 | 偏置建议 |
|---|---|---|---|---|---|---|---|
| 力矩→速度 | 辨识 | 断 | 断 | 闭 | 1/(Js+B) 纯机械 | 力矩 | 小值，让轴缓慢爬行 |
| 电流→速度 | 辨识 | 断 | 断 | 闭 | Kt/(Js+B)（含 Kt） | Iq 电流 | 小值，让轴缓慢爬行 |
| 速度→位置 | 辨识 | 断 | 闭 | 闭 | 速度闭环 × 1/s | 速度 | **必须为 0** |
| 电流→电流 | 验证 | — | — | 闭 | 电流闭环 T(s) | Iq 电流 | 堵转，0.3~1.0 倍额定 |
| 速度→速度 | 验证 | 旁路 | 闭 | 闭 | 速度闭环 T(s) | 速度 | 10%~30% 额定转速 |
| 位置→位置 | 验证 | 闭 | 闭 | 闭 | 位置闭环 T(s) | 位置 | 定位点附近 |

### 5.2 逐模式说明

**力矩→速度（纯机械辨识）**
速度环、位置环断开，电流环闭合当转矩源。注入力矩正弦，测速度响应。这是最"干净"的机械辨识：测到的就是 1/(Js+B)，拟合出惯量 J 和粘性摩擦 B，是速度环/位置环整定的直接输入。若力矩常数未知，用下一档"电流→速度"，结果为 J/Kt、B/Kt 等效值。

**电流→速度（含 Kt 的机械辨识）**
与上一档唯一的区别是注入 Iq 电流而非力矩，测到的传函里多乘了一个 Kt。当 kt 不准或不想依赖它时用这档，拟合出的"等效惯量"可直接用于以电流为单位的增益换算。

**速度→位置（位置对象辨识）**
位置环断开，速度环闭合，注入速度正弦，测位置（= ∫速度）。测到的是"速度闭环 × 积分器"。它用于确定位置环 P 增益：位置环 Kp 直接限制在速度闭环带宽的 1/5~1/3，本模式给出的速度闭环带宽就是那个约束的实测来源。

**电流→电流（电流环验证）**
全环只用电流环，注入 Iq 给定正弦，测 Iq 反馈。给出电流闭环带宽、峰值和裕度——它是所有外环整定的基础（外环带宽受限于它），也是验证电流环 PI 与电感/电阻参数是否匹配的手段。

**速度→速度（速度环验证）**
位置环旁路，速度环闭合，在速度给定端叠加正弦，测速度反馈。验证速度环整定是否达标；同时本模式的低频段也可用于反推速度闭环带宽，供位置环整定参考（一档两用）。

**位置→位置（位置环全链验证）**
全环闭合，注入位置给定正弦，测位置反馈。验证整条链（位置 P + 速度 PI + 电流 PI + 机械）的综合表现，是最终的验收测试。

## 6. 偏置策略：为什么要加、加在哪、加多大

### 6.1 核心规则

**偏置永远加在激励注入的那条信号线上**——注入电流就加电流偏置，注入速度就加速度偏置。被测环是断开的那个环不存在"给定值"，自然也谈不上它的偏置。

例：速度环辨识（力矩→速度）时，速度是**输出量**而非输入量，不存在"速度偏置"这个设置项；让轴离开零速的手段是给注入的力矩/电流加直流偏置。

### 6.2 两个方向，两种目的

**辨识时加小偏置——避开静摩擦死区**

一阶模型 1/(Js+B) 假设摩擦是纯粘性的（摩擦力 ∝ 转速），但零速附近存在静摩擦：小幅正弦力矩可能根本推不动轴，或轴"走走停停"（爬行蠕动）。后果是低频段增益偏低、相位失真，J/B 拟合直接报废。加小力矩偏置让轴以 ω₀ = T_bias/B 缓慢爬行，工作点进入粘性摩擦区，数据才符合模型假设。

**验证时加较大偏置——钉住线性工作点**

闭环验证要测的是线性区的频响，偏置把系统拉离所有零点附近的非线性区：

- 电流环：堵转 + 0.3~1.0 倍额定电流偏置（避开逆变器死区补偿区、零电流非线性）；
- 速度环：10%~30% 额定转速空载偏置（避开零速摩擦跳变、编码器低速噪声）；
- 位置环：在定位点或匀速跟踪态附近测试。

### 6.3 特殊与危险情形

| 情形 | 原因 | 对策 |
|---|---|---|
| 速度→位置偏置必须为 0 | 位置 = ∫速度，任何速度偏置都使位置线性发散，撞机械限位 | 偏置置 0；正弦注入的位置摆幅 ≈ amp/(2π·f)，开始前估算 |
| 力矩/电流辨识的偏置使轴单向爬行 | 全扫频周期行程 = ω₀ × 总时长，可能到限位 | 先估算总行程；行程紧就减小偏置或缩短扫频范围 |
| 速度→速度的偏置是持续旋转 | 关节行程有限（如 ±π rad），20 rad/s 几秒即到头 | 输出端脱载测试，或行程受限时改小幅值纯交流注入（牺牲低速段精度） |
| 电流环堵转验证温升快 | 无反电动势、无风冷，铜损全部变热 | 缩短单频点测量时间，频点间留冷却间隔 |

## 7. 结果怎么用

### 7.1 辨识 → 带宽法整定

对"力矩→速度/电流→速度"的实测点做一阶拟合 G(s) = 1/(Js+B)：每个频点取 1/H(jω)，其实部恒为 B、虚部为 ω·J，最小二乘即得 Ĵ、B̂，转折频率 = B/(2πJ)。然后按带宽法换算：

| 环 | 辨识输入 | 换算公式 | 带宽约束 |
|---|---|---|---|
| 电流环 PI | L̂、R̂ | Kp = ωc·L̂，Ki = ωc·R̂（零点对消对象极点） | ωc ≤ 2π·f_sw/10，保守取 f_sw/20 |
| 速度环 PI | Ĵ（B̂ 通常忽略） | Kp = ωv·Ĵ，Ki = Kp·ωv/4 | ωv ≤ ωc/5 |
| 位置环 P | 速度闭环带宽 ωv | Kp = ωp | ωp ≤ ωv/5（保守）~ ωv/3 |

要点：

- 电流环用零极点对消（Kp/Ki = L/R），这是最简单也最鲁棒的做法；
- 速度环 Ki 与 Kp 的比值（零点频率）取 ωv/4 左右，介于"响应快"与"噪声放大"之间；
- 带宽约束的物理逻辑是**级联解耦**：外环必须比内环慢得多，内环才能被当作理想执行器；
- 没有模型时的试凑法只做兜底，不作为主路径。

### 7.2 验证 → 闭环指标

从实测闭环传函 T(jω) 提取：

| 指标 | 定义 | 常见验收线 |
|---|---|---|
| -3dB 带宽 | \|T\| 相对低频参考跌落 3dB 的频率 | 与设计值偏差 ±20% 内 |
| 闭环峰值 Mr | 低频参考之上的最大增益 | 电流环通常 < 2dB |
| 相位裕度 PM | 开环 L 在增益穿越点的相位裕量 | ≥ 45° |
| 增益裕度 GM | 开环 L 在 -180° 穿越点的增益距离 | ≥ 6dB |

PM/GM 无法直接测量，标准做法是由闭环传函**反推开环**：L = T/(1−T)。要清醒认识它的可靠性边界：

- **低频段不可信**：T≈1 时 1−T 有效数字不足，噪声被剧烈放大，反推结果只在中高频（穿越区附近）可信；
- **要求同源同步采样**：给定与反馈必须同一时间基准采样，任何相位失配都会直接污染裕度计算；
- 低频噪声点应从裕度计算中剔除，而不是硬算出一个假的 PM/GM。

## 8. 实操要点与常见坑

### 8.1 测量质量

| 要点 | 说明 |
|---|---|
| 采样率 | ≥ 10×最高扫频频率；对电流环这类高带宽对象建议 ≥ 5kHz |
| 测量周期数 | 每频点至少 1 个完整信号周期，2~4 个更稳；按"测量时长约 2s"自适应配置 |
| 稳定段/测量段分离 | 每个频点切换后先等暂态衰减（稳定段），再采数据（测量段），数据只取测量段 |
| SNR | 信噪比 < 10dB 的点只降精度不否定测量，标注警告；幅值太小则该点作废 |
| PLL/滤波影响 | 编码器测速的 PLL 滤波带宽会压制高频速度响应——速度相关模式的高频段读数偏低时先怀疑它 |
| 频点分布 | 对数分布（低频密、高频疏）适合辨识；步进 1Hz 适合精细验证 |

### 8.2 安全清单（关节电机/行程受限系统）

1. **扫频前估算最大行程**：偏置爬行行程 = ω₀ × 总时长；正弦摆幅 ≈ amp/(2π·f)（对位置类输出）；
2. **速度→位置模式偏置必须为 0**——这是唯一"必须"级别的配置项；
3. **持续旋转模式（速度→速度）确认行程充足**或输出脱载；
4. **堵转测试控制时长**，防止绕组过热；
5. **扫频必须从 READY 状态启动**，随时可停；
6. **首次上电先用小幅值**（如 10% 预算幅值）确认方向、量纲、行程安全，再加到正式幅值。

### 8.3 常见误区

| 误区 | 正解 |
|---|---|
| "开环扫频 = 所有环都断开" | 只有被测环断开，内环必须闭合当执行器 |
| "给速度环辨识设速度偏置" | 偏置加在注入通道上；速度环断开时不存在速度给定 |
| "偏置越大越线性" | 辨识要小偏置避开死区即可，大了引入非线性（饱和、温升） |
| "闭环测出的带宽就是性能" | 带宽是必要条件，还要看 Mr/PM/GM；裕度不足的高带宽是振荡隐患 |
| "低频点反推的 PM 也是准的" | L=T/(1−T) 只在中高频可信，低频 1−T 淹没在噪声里 |
| "PM/GM 达标就万事大吉" | 频域指标不覆盖抗扰刚度、饱和恢复等时域行为，验收应两者结合 |

## 9. 一页总结

```
级联链:  θ* → [位置P] → ω* → [速度PI] → iq* → [电流PI] → Uq → [电气] → T → [机械1/(Js+B)] → ω → ∫ → θ

方向一·辨识(整定前): 断被整定环, 闭内环, 注入对象输入端
    力矩→速度 / 电流→速度  ⇒ 拟合 J/B ⇒ 带宽法换算速度环/位置环 PID
    速度→位置              ⇒ 速度闭环带宽 ⇒ 位置环 Kp 上限

方向二·验证(整定后): 全环闭合, 注入各环给定端
    电流→电流 / 速度→速度 / 位置→位置 ⇒ 带宽 / Mr / PM / GM 验收

偏置: 永远加在注入通道上
    辨识=小偏置避静摩擦死区; 验证=大偏置钉线性工作点; 速度→位置偏置必为0

不达标: 形态不对→模型错→回辨识;  形态对指标差→参数差→微调再验证
```
