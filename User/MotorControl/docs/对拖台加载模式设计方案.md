# 对拖台加载模式设计方案

> 文档状态：第一版已实施（2026-08-21）：协议 CSV / 下位机固件 / 上位机命令层已合入，待台架验收；第二、三版未实施
>
> 适用工程：`JointMotor`（负载电机侧固件 + 上位机）
>
> 新增命令：`0x60~0x67` 负载模拟段（8 个命令码与 8 个对拖特有模式一一对应）；补实现 `0x36 ZERO_FORCE`（零转矩自由）
>
> 实施顺序：先补协议 CSV（`joint_motor_command_list.csv`），下位机与上位机再同步实现；上位机仅命令层支持，不做专用面板

## 1. 目的与范围

将本电机用作对拖台的加载电机，按"基础核心 → 标准进阶 → 专业测试"三级实现测功机负载功能。本方案给出：

1. 需求模式与现有固件能力的逐项对照，明确真正的新增范围；
2. 新增命令的协议载荷设计（`0x60~0x67` 八个命令码覆盖全部新增需求）；
3. 各模式的算法设计与固件分层实现方案；
4. 对拖台特有的安全问题（母线泵升、故障输出策略、停机语义）。

范围约束：

1. 已有模式（主动转矩、恒速拖动、位置锁定）不做改动，仅在文档中给出对拖台用法；
2. 沿用现有模式架构（`motor_mode_xxx.c` + `s_mode_table` 分发 + `transition_mgr` 过渡），不引入新框架；
3. 全部模式在本方案内完成设计，实施分期严格对应需求的三版优先级（第一版必做基础 4 项 → 第二版标准进阶 → 第三版按需扩展）。

## 2. 需求与现状对照

12 项需求模式逐项核对现有固件：

| # | 对拖台模式 | 需求版本 | 现状 | 结论 |
|---|---|---|---|---|
| 1 | 被动恒转矩加载 | 第一版 | 无。`TORQUE 0x12` 是方向固定的主动转矩 | **新增**（0x60） |
| 2 | 主动转矩（四象限） | 第一版 | `TORQUE 0x12` 已完成，峰值限幅，电动/发电双状态天然支持 | 直接可用 |
| 3 | 恒速拖动 | 第一版 | `VELOCITY 0x14` 已完成 | 直接可用 |
| 4 | 零转矩自由 | 第一版 | `ZERO_FORCE 0x36` 预留，未实现 | **补实现**（iq 给定强制 0） |
| 5 | 动态转矩加载（阶跃/正弦/方波） | 第二版 | 正弦注入在扫频 0x76 有基础设施，无通用波形发生器 | **新增**（0x61） |
| 6 | 位置锁定（堵转） | 第二版 | `POSITION_TORQUE 0x17`（位置环+力矩限幅）即堵转模式 | 直接可用 |
| 7 | 平方转矩负载 | 第二版 | 无 | **新增**（0x62） |
| 8 | 恒功率负载 | 第二版 | 无 | **新增**（0x63） |
| 9 | 摩擦负载 | 第二版 | 无 | **新增**（0x64） |
| 10 | 惯量模拟 | 按需 | 无 | **新增**（0x65） |
| 11 | 工况谱复现 | 按需 | 无 | **新增**（0x66） |
| 12 | 冲击/过载 | 按需 | 无 | **新增**（0x67，独立模式 + 分层过载限幅） |

**核心结论**：在 `0x60~0x6F` 段新增 8 个对拖台专用命令码（`0x60~0x67` 与 8 个对拖特有模式一一对应，`0x68~0x6F` 预留扩展）+ 补实现 `0x36 ZERO_FORCE`，加上 3 个直接可用的已有模式（0x12/0x14/0x17），即可完整覆盖 12 项需求。第一版真正要写的固件代码只有两个模式入口（被动恒转矩 + 零转矩自由），工作量最小。

零转矩自由与相关状态的区分：

| 状态 | 实现 | 旋转时表现 | 适用场景 |
|---|---|---|---|
| `IDLE`/失能（零矢量） | 三相绕组短接 | 短路制动转矩 | 常规停机 |
| **`ZERO_FORCE`（本方案）** | **电流环闭环，id=iq 给定强制 0** | **无电磁转矩，近似自由滑行** | **机械调试、换被测电机、安全停机待机、校编码器零位（"脱开离合器"）** |
| `TORQUE 0x12` 设 0 | 电流环闭环 iq=0 | 与 ZERO_FORCE 等价但无模式语义 | 临时卸载 |

说明：iq=0 闭环时电流环维持电流为零，不输出平均电磁转矩；转子仅受机械摩擦与电机固有齿槽定位转矩（磁阻转矩，任何电流控制无法消除也不需要消除），满足"轴系可无阻力转动"。相比失能态的零矢量短路（反拖时产生不可控短路制动电流），使能态的 ZERO_FORCE 才是真正的"脱开"。

## 3. 命令与协议设计

### 3.1 命令码分配（0x60~0x6F 负载模拟段）

现有分组注释中 `0x50~0x6F` 为轨迹同步段，实际轨迹类仅占用 `0x50~0x5D`，`0x5E~0x6F` 空闲。本方案将分组边界调整为：**`0x50~0x5F` 轨迹同步 | `0x60~0x6F` 负载模拟**，`jm_cmd_def.h` 头部分组注释同步更新。

命令码按需求三版优先级升序分配：`0x60` 第一版 → `0x61~0x64` 第二版 → `0x65~0x67` 按需扩展，码值顺序即实施顺序：

| 命令码 | 名称 | 模式 | 需求版本 |
|---|---|---|---|
| `0x60` | `JM_CMD_PASSIVE_TORQUE` | 被动恒转矩加载 | 第一版 |
| `0x61` | `JM_CMD_DYNAMIC_TORQUE` | 动态转矩加载（阶跃/正弦/方波/脉冲） | 第二版 |
| `0x62` | `JM_CMD_QUADRATIC_LOAD` | 平方转矩负载（风机/水泵） | 第二版 |
| `0x63` | `JM_CMD_CONSTANT_POWER` | 恒功率负载（主轴/卷绕） | 第二版 |
| `0x64` | `JM_CMD_FRICTION_LOAD` | 摩擦负载（库仑+粘性） | 第二版 |
| `0x65` | `JM_CMD_INERTIA_SIM` | 惯量模拟 | 按需 |
| `0x66` | `JM_CMD_DUTY_PROFILE` | 工况谱复现（下载/回放） | 按需 |
| `0x67` | `JM_CMD_IMPACT_LOAD` | 冲击/过载负载（分层限幅） | 按需 |
| `0x68~0x6F` | — | 预留对拖台扩展（如惯量+摩擦组合、多轴联动加载） | — |
| `0x36` | `JM_CMD_ZERO_FORCE` | 零转矩自由（命令码已有，补实现） | 第一版 |

协议版本升至 1.5（当前 1.4）；`feature_flags` 启用 bit6（`JM_FEAT_LOAD_SIM`，bit0~bit5 已占用），上位机据此识别固件能力。

每个模式独立命令码（而非单命令码+子类型）的理由：本协议核心约定是"CMD 数值即 `ctrl_mode_e`，固件可直接把 CMD 当控制模式分发"（见 `jm_cmd_def.h` 头注）。独立命令码可完整复用 `app_set_mode → process_ctrl_cmd → s_ctrl_mode_to_run_state → motor_ctrl_dispatch` 的标准分发路径，无需像扫频 0x76 那样单独写 handler；载荷也可按各模式语义定制，不再需要 subtype 与泛型 p1~p4 字段。

新增命令同步补入 `Protocol/docs/joint_motor_command_list.csv`（协议唯一事实源），下位机与上位机的载荷布局严格按 CSV 实现。

### 3.2 各命令载荷格式

| 命令码 | 载荷 | 字段语义 |
|---|---|---|
| `0x60` | 4B `{T_set: f32}` | 制动转矩设定（N·m），静止时输出 0 |
| `0x61` | 20B `{waveform: u8, flags: u8, reserved: u16, amp: f32, freq: f32, bias: f32, duration: f32}` | waveform：0=阶跃 1=正弦 2=方波 3=单脉冲；flags.bit0=被动方向（叠加在被动转矩基础上）；amp 幅值（N·m）、freq 频率（Hz）、bias 偏置（N·m）、duration 时长（s，0=连续） |
| `0x62` | 4B `{k: f32}` | 平方系数 k = T_rated/ω_rated²（N·m·s²/rad²），由上位机按额定点换算 |
| `0x63` | 4B `{P: f32}` | 恒功率值（W） |
| `0x64` | 8B `{T_c: f32, b: f32}` | 库仑摩擦（N·m）+ 粘性系数（N·m·s/rad） |
| `0x65` | 8B `{J_sim: f32, T_bias: f32}` | 模拟惯量（kg·m²）+ 可选恒转矩基载（N·m） |
| `0x66` | 8B 头 `{seq_ctrl: u8, flags: u8, reserved: u16, block_id: u32}` + 变长数据 | seq_ctrl：0=下载数据块 1=启动 2=停止 3=清空；flags.bit0=循环回放、bit1=通道选择（0=转矩谱/1=转速谱）；下载块在头后追加 `{点数:u16, 压缩数据 ≤16点×4B}`（载荷总长 ≤74B），其余子命令仅 8B 头 |
| `0x67` | 20B `{waveform: u8, flags: u8, reserved: u16, ratio: f32, period: f32, width: f32, duration: f32}` | waveform：0=周期脉冲 1=方波循环 2=单次突变冲击；flags.bit0=被动方向（方向跟随转速）；ratio 过载倍数（1.0~2.0，相对 peak_torque）；period 周期（s）；width 脉宽（s，方波固定 50% 占空比可置 0）；duration 总时长（s，0=连续） |
| `0x36` | 0B（无载荷） | 进入即 iq=0 闭环 |

统一校验规则（`JM_ERR_OUT_OF_RANGE`）：

1. 转矩类参数 ≤ `peak_torque`；功率 ≤ `peak_torque × max_speed`；k、b、freq、J_sim > 0；ratio ∈ [1.0, 2.0]；
2. freq ≤ 控制频率 / 10（波形分辨率下限，同扫频约束）；period ≥ 2 × width（脉冲必须留间歇期）；
3. J_sim ≤ 上限系数 × 轴系惯量（失稳保护，见 4.5）；
4. `0x61`/`0x67` 载荷 20B、`0x66` 下载块 ≤74B，均超 CAN 经典帧 8B，走既有请求分包（多帧协议已支撑）；CAN FD 单帧直发。

停止语义：对拖模式作为标准运动指令，STOP（0x06）停止——负载输出立即清零（转矩指令置 0，不做减速过渡），状态机回 READY。工况谱回放中 STOP 额外使序列游标失效并清缓冲；冲击/过载模式 STOP 同步复位过载累计计时与冷却状态。

应答：启动/热更新回普通 ACK；`0x66` 下载块 ACK 回 `{已收点数:u16, 总点数:u16, 保留:u32}`。

### 3.3 启动与模式切换规则

| 场景 | 行为 |
|---|---|
| READY 态收对拖命令 | 校验通过 → 进 RUN，首个周期即按公式输出（走标准 READY→RUN 路径与平滑过渡起点） |
| RUN 态重发同命令 | 参数热更新，逐拍生效（波形相位/序列游标不重置） |
| RUN 态对拖模式间切换 | 直接发新命令码，`transition_mgr` 平滑过渡（转矩类参考渐变，硬限幅兜底） |
| RUN 态常规模式 ↔ 对拖模式 | 同上，标准运动指令切换路径（与 0x12/0x14 互切一致） |
| READY 态收 0x36 ZERO_FORCE | 进 RUN，id=iq=0 闭环（无载荷） |

工况谱 0x66 例外：下载块（seq_ctrl=0）在任意状态均可执行（仅写 RAM 缓冲不切状态机）；启动回放（seq_ctrl=1）要求 READY 态且序列已收齐。

## 4. 模式算法设计

### 4.1 被动恒转矩（0x60，第一版）

```c
/* 方向判定: 滞回状态机(进入阈值 ω_dead / 退出阈值 ω_dead/2) */
if (dir == 0)                            /* 无载荷态 */
    dir = (vel >= w_dead) ? +1 : (vel <= -w_dead) ? -1 : 0;
else if (dir > 0)                        /* 正向制动中 */
    dir = (vel <= -w_dead) ? -1          /* 反向拖动: 换向 */
       : (vel < w_dead/2) ? 0            /* 减速到退出阈值: 卸载 */
       : +1;
else                                     /* 反向制动中 */
    dir = (vel >= w_dead) ? +1 : (vel > -w_dead/2) ? 0 : -1;

/* 输出级: 转矩速率限制(斜坡), 给定值缓慢到达目标 */
T_out = ramp(T_out, -dir * T_set, 5.0 /* N·m/s */);
```

要点：

1. **静止时转矩为 0、绝不主动拖动**是被动模式的核心语义——被测电机静止时负载电机零输出，被带动后才建立制动转矩，全程工作在发电制动象限；
2. **两级防抖缺一不可**：
   - 滞回方向判定抑制 0↔±1 斩波（PLL 噪声跨越单一阈值）；
   - **输出转矩速率限制**抑制 +1↔-1 换向斩波——机械震动会让速度反复越过换向阈值，方向判定层无法根除，必须在输出级把给定转矩的每拍变化限制在 ramp·dt 内（换向平滑过零、跳变能量谱被斜坡滤除）。实测仅滞回仍残留明显震动，加斜坡后根除；
3. 死区内严格零输出而非线性过渡：线性过渡会把速度噪声放大为波动转矩（增益 T_set/ω_dead），与电流环耦合形成自持极限环；
4. 斜坡速率 5 N·m/s（转矩建立约 T_set/ramp，0.1 Nm → 20ms），兼顾平滑性与响应；如需更柔/更快可在 `LOAD_SIM_TORQUE_RAMP_NM_S` 调整；
5. `ω_dead` 作为运行时参数挂 `motor_param`（`load_sim_dead_zone_rad_s`，默认 0.5，范围 0.05~5.0），可通过 0xE1 参数读写调整——震动残余时可增大此值；
6. 输出统一经 `motor_mode_clamp(-peak_torque, +peak_torque)` 硬限幅；内部斜坡每拍变化量远小于参考平滑层阈值，两层平滑无冲突。

典型用法：被测电机速度模式 + 负载被动恒转矩 → 测转矩-转速外特性、负载温升、稳态效率。

### 4.2 零转矩自由（0x36 补实现，第一版）

按需求定义实现"q 轴电流给定强制为 0"：

1. `motor_mode_zero_force.c`（新文件）：

```c
void motor_mode_zero_force_run(motor_ctrl_t *ctrl)
{
    motor_ref_t *ref = &ctrl->ref;
    ref->pos_profile = MOTOR_PID_PROFILE_POSITION;
    ref->vel_profile = MOTOR_PID_PROFILE_VELOCITY;
    ref->ctrl_type = REF_CTRL_CURRENT;   /* 电流环闭环 */
    ref->id = 0.0f;                      /* 给定强制为 0 */
    ref->iq = 0.0f;
}
```

2. 无需新增参考类型、无需触碰 PWM 通道管理——复用现有电流环闭环（`REF_CTRL_CURRENT`），实现量约 15 行；
3. `s_mode_table` 将 `RUN_STATE_ZERO_FORCE` 从 legacy 占位指向新函数，`motor_mode_legacy_run` 中 ZERO_FORCE 分支移除；
4. 该模式下反馈（编码器/电流/母线）照常刷新，上位机可继续观察轴系状态，校准编码器零位、机械调试期间监控不中断。

### 4.3 动态转矩加载（0x61，第二版）

在主动/被动转矩基础上给转矩指令叠加标准波形，本地波形发生器（不依赖上位机周期下发，消除链路抖动）：

```c
/* 32 位 NCO 相位累加，复用扫频 phase_inc 机制 */
phase += phase_inc;                    /* phase_inc = f / f_ctrl * 2^32 */

switch (waveform) {
case STEP:   w = 1.0f;                             break;  /* 进入即阶跃到 bias+amp */
case SINE:   w = sinf(phase * TWO_PI / 2^32);      break;
case SQUARE: w = (sinf(...) >= 0) ? 1.0f : -1.0f;  break;  /* 周期换向循环加载 */
case PULSE:  w = (elapsed < hold_s) ? 1.0f : 0.0f; break;  /* 单脉冲，hold=duration */
}
T_raw = bias + amp * w;
T_raw = (elapsed >= duration && duration > 0) ? bias : T_raw;  /* 时长到即收敛到偏置 */

if (flags & PASSIVE_DIR)                        /* 在被动转矩基础上叠加波形 */
    T = -sign(ω) * fabsf(T_raw);                /* 方向跟随转速，含死区衰减 */
else                                            /* 在主动转矩基础上叠加波形 */
    T = T_raw;                                  /* 方向由指令固定，电动/发电均可 */
```

- 阶跃→阶跃响应测试（响应时间、超调量）；正弦→转矩脉动抑制/抗扰验证；方波→换向/循环加载；单脉冲→冲击模拟；
- 幅值/频率/周期（时长）全部可配：duration = 0 表示连续输出（方波循环、正弦脉动的常态），> 0 表示到时后收敛到 bias（限时试验）；
- 运行时状态（phase_acc、waveform、参数快照、elapsed）仿 `sweep_*` 字段挂 `motor_ctrl_t`，热更新参数时不重置相位。

### 4.4 特性负载（0x62/0x63/0x64，第二版）

三种负载共用"方向跟随转速"框架，按真实负载规律实时计算转矩，仅 T(ω) 曲线不同：

```
 T ↑
   |     恒功率(限幅)  ____———— 平方转矩
   |            ____——
   |        __——        ___———— 摩擦(库仑+粘性)
   |    __——      _____
---●———————————————●——————→ ω      (全部位于二/四象限，纯制动)
   |  被动恒转矩(死区段过零)
```

- **平方转矩**（风机/水泵）：`T = -sign(ω)·k·ω²`，k 由上位机按额定点换算（k = T_rated/ω_rated²）；
- **恒功率**（机床主轴/卷绕）：`T = -sign(ω)·min(P/|ω|, T_peak)`，低速段转矩发散必须钳位到峰值转矩，`|ω| < ω_dead` 时同样走死区衰减；
- **摩擦**（导轨/传动机构）：`T = -(T_c·lin(ω/ω_dead) + b·ω)`，其中 `lin(x)=clamp(x,-1,1)`——库仑项用死区线性化替代 sign() 防抖振（恒定库仑摩擦 + 粘性摩擦组合），粘性项天然连续。

### 4.5 惯量模拟（0x65，按需）

不用更换机械飞轮，通过算法实时补偿转矩模拟不同转动惯量：

```c
/* 加速度估计：差分 + 一阶低通（截止 ~50Hz，滤除编码器量化噪声） */
a_raw  = (vel - vel_prev) / dt;
a_est += LPF_ALPHA * (a_raw - a_est);

T = -J_sim * a_est - sign(ω) * T_bias;   /* T_bias 提供可选的恒转矩基载叠加 */
```

设计要点与风险控制：

1. **本质是正反馈**：模拟转矩反作用于轴系，`J_sim` 超出真实轴系惯量过多会振荡失稳。稳定上限与控制周期、滤波器延迟相关，工程经验约 `J_sim ≤ 2~3 × J_real`。固件侧双保险：
   - 校验规则：`J_sim ≤ K_INERTIA_MAX(默认 3.0) × J_load`，`J_load` 取 L6.1 负载惯量标定结果（未标定时回落到 `motor_info` 手填参考值，缺省拒绝启动并提示先标定）；
   - 输出经 `peak_torque` 硬限幅 + 振荡看门狗：检测转矩指令高频翻转（单位时间内符号翻转次数超阈值）自动停止并回 READY；
2. 速度源用 PLL 观测器输出（已有三种速度估计可配），比裸差分噪声小一个量级；
3. 前置条件：L6.1 负载惯量标定 + 速度观测器配置为 PLL；验收以"被测电机阶跃速度指令下超调与理论二阶系统一致（±15%）"为通过标准。

### 4.6 工况谱复现（0x66，按需）

导入实际工况数据（汽车行驶工况、机器人关节轨迹、压缩机负载曲线），按时间序列逐点复现转矩/转速变化：

```
上位机导入实测工况(CSV/轨迹)
        │  ① 分块下载 (seq_ctrl=0, 任意状态可执行)
        ▼
固件序列缓冲(RAM 环形, 2048 点 × {t:u16(ms), 值:i16(0.01N·m 或 0.1rad/s)} = 8KB)
        │  ② 启动回放 (seq_ctrl=1, READY 态)
        ▼
控制 ISR 按时间戳线性插值输出 T(t) 或 ω(t) ──③ 到时/停止(seq_ctrl=2/STOP)──> 回 READY
```

- **回放通道**：flags.bit1 区分转矩通道（负载电机输出 T 序列，`REF_CTRL_TORQUE`）与转速通道（负载电机按速度谱拖动，`REF_CTRL_VELOCITY`）——覆盖"复现转矩/转速变化"两类工况；
- **下载协议**：`seq_ctrl=0` 载荷为 `{block_id:u32, 点数:u16, 压缩数据}`，每包最多 16 点（多帧协议已有分包重组支撑），块间 CRC 校验，全部块收齐后 ACK 回收点数；8KB 缓冲独立静态区（不复用 1024 点扫频表）；
- **时间基准**：回放时钟用控制周期计数（10kHz 软件时基，1ms 精度足够，工况谱不需要 µs 级）；
- **插值**：相邻采样点间线性插值到控制周期，避免阶梯指令激励出高频谐振；
- **循环回放**：flags.bit0 决定序列到末尾停机或循环，支撑全工况可靠性老化验证；
- **退化方案**：>2048 点的长工况，上位机退化为流式下发（UART 1kHz 可行），精度略差但无长度限制，复用现有实时命令通道。

### 4.7 冲击/过载负载（0x67，按需）

独立模式承载"周期性短时过载转矩、突变冲击转矩"，测试被测电机及驱动的过载能力、机械强度、故障保护阈值：

```
波形门控 g(t) ∈ {0, ±1} ──×── ratio × peak_torque ──> 分层限幅器 ──> T_out
                                                    │
                            过载累计窗口 / 冷却期（模式内部状态）
```

- **周期脉冲**（waveform=0）：每 `period` 输出 `width` 宽度的过载转矩，间歇期回 0；
- **方波循环**（waveform=1）：50% 占空比双向换向，模拟周期性换向冲击；
- **单次突变冲击**（waveform=2）：进入即输出 `width` 宽过载脉冲后回 0，`duration` 到自动收敛；
- **分层限幅器**（模式内置，替代该模式内的单层限幅）：

```c
T_limit = ratio * peak_torque;   /* 过载累计时间 < overload_time 时允许 */
if (overload_time 耗尽) {
    T_limit = peak_torque;       /* 强制回落连续限幅 */
    进入 overload_cooldown 冷却期，期间禁止再次过载;
}
```

- `overload_time`/`overload_cooldown` 作为运行时参数挂 `motor_param`（默认 1000ms / 10000ms），`ratio/period/width` 随命令载荷下发；
- 过载期间温度保护照常生效（过温 FAULT 优先级高于过载窗口）；
- 与 0x61 动态转矩的分工：0x61 幅值恒 ≤ `peak_torque`（连续能力内的波形激励），0x67 专门管理"越过 `peak_torque` 的短时过载窗口"，两者限幅策略不混用。

## 5. 安全设计（对拖台特有）

### 5.1 发电制动与母线泵升

负载电机全程工作在发电象限，能量回灌直流母线：

1. 固件已有 `protect_over_voltage` 过压保护（默认 58 V，`fault_check` 周期检测，触发即 FAULT）；
2. **硬件前提**：直流电源必须能吸收回馈能量（双象限电源），否则需外接制动电阻——普通台式电源会反复触发过压 FAULT，此为硬件配套项，需在对拖台搭建时确认；
3. 建议测试流程：首次加载从 10% 额定转矩起步，确认母线电压回升幅度后再逐步加载。

### 5.2 故障输出策略

现有 FAULT/ESTOP 动作是 `REF_CTRL_IDLE` → 零矢量短路。对拖台高速反拖时，零矢量短路电流 ≈ 反电动势/相阻抗，可能远超额定时引发二次过流。处理：

1. 第一版：文档明确"FAULT 前先降速/小转矩起步"操作规程，过压阈值留 20% 裕量；
2. 按需版本：增加故障输出策略参数（`fault_output_mode`：零矢量/高阻），对拖台配置为高阻（PWM 关断），彻底消除二次过流风险。

### 5.3 停机与模式退出语义

| 场景 | 行为 | 说明 |
|---|---|---|
| 对拖模式内收 STOP | 转矩经停机过渡渐变卸载到零 → READY | 与力矩模式停机语义一致，避免被测电机侧负载突变冲击；转速不归本机管，仅卸载转矩不减速 |
| ZERO_FORCE 内收 STOP | iq=0 保持 → READY | 安全停机待机语义 |
| 工况谱回放中收 STOP | 序列游标失效并清缓冲 → READY | 防止再次启动残留旧数据 |
| 冲击/过载中收 STOP | 立即清转矩 → READY，过载累计计时与冷却状态复位 | 冷却期不跨模式残留 |
| 通信丢失 | 走既有 CAN loss timer 降级 | 已有机制复用 |
| 惯量模拟振荡看门狗触发 | 自动停机回 READY，fault_code 置警告位 | 失稳自恢复 |
